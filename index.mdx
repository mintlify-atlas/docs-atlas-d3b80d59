Saltbox is an Ansible-based solution for rapidly deploying a fully-configured, Docker-containerized cloud media server on Ubuntu 22.04 or 24.04. It automates everything from OS-level hardening and Docker installation to setting up Traefik as a reverse proxy, mounting cloud storage via Rclone, and deploying media management applications — all accessible via your own domain with automatic TLS certificates.

## What Saltbox Deploys

Saltbox provisions an entire self-hosted media stack through Ansible tags — each tag maps to a discrete, idempotent role.

## How It Works

<Steps>
  <Step title="Prepare your server">
    Start with a fresh Ubuntu 22.04 or 24.04 LTS server. Ensure you have a registered domain pointing to your server's IP and a Cloudflare account (or supported DNS provider).
  </Step>
  <Step title="Configure your settings">
    Fill in `accounts.yml`, `settings.yml`, and `providers.yml` with your credentials, domain, and cloud storage remotes. These files drive every role in the playbook.
  </Step>
  <Step title="Run the playbook">
    Execute `ansible-playbook saltbox.yml --tags saltbox` to deploy the full stack, or use individual tags like `--tags plex` or `--tags sonarr` to install specific services.
  </Step>
  <Step title="Access your services">
    Each service is automatically assigned a subdomain on your domain (e.g. `plex.yourdomain.com`) with a valid TLS certificate, protected by your chosen authentication layer.
  </Step>
</Steps>

<Note>
  Saltbox has no dashboard or GUI of its own. All setup and ongoing management is performed via text editors and the command line using Ansible.
</Note>
